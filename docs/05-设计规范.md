# 05 · 设计规范

> 来源：[src/style.css](../src/style.css) 的 `:root` 与全局样式
> 原则：**所有数值都必须来自 CSS 变量**，禁止在组件里写死颜色与圆角

---

## 1. 设计原则

| 原则 | 含义 |
|---|---|
| **单色主导** | 全站只有一个品牌绿，其余色都是**语义色**（表达数据含义），不做花哨配色 |
| **数据优先** | 界面的主角是数字，颜色用来区分数据含义而非装饰 |
| **移动优先，桌面增强** | 小屏单列堆叠，大屏逐步加宽与并排 |
| **圆角柔和** | 全站统一大圆角（12~20px），营造轻量感 |
| **克制的层级** | 用边框 + 极淡阴影分层，不用重投影 |

## 2. 色板

### 2.1 品牌色

| Token | 值 | 用途 |
|---|---|---|
| `--brand` | `#0fae8e` | 主色：图标、强调、focus 环 |
| `--brand-strong` | `#0a8f74` | 主色深：选中态文字、强调数字 |
| `--brand-soft` | `#e4f6f1` | 主色浅：选中底、标签底 |
| `--brand-grad` | `linear-gradient(135deg, #12b886, #0fae8e)` | 渐变：Hero 卡、Logo、侧边栏底板、指标卡左条 |

### 2.2 中性色（文字层级）

| Token | 值 | 用途 |
|---|---|---|
| `--text` | `#0f1c17` | 标题、关键数字 |
| `--text-sub` | `#5d6b65` | 正文、字段标签 |
| `--text-faint` | `#93a09a` | 辅助说明、单位、占位 |
| `--border` | `#e7ecea` | 常规边框 |
| `--border-strong` | `#d8e0dd` | 虚线边框（添加按钮） |
| `--surface` | `#ffffff` | 卡片、弹窗 |
| `--surface-2` | `#f7f9f8` | 次级面：摘要条、输入框底 |
| `--bg` | `#f3f6f5` | 页面底色 |
| `--bg-grad` | `linear-gradient(180deg, #eef5f3, #f3f6f5)` | ⚠️ **曾经定义但未使用**，见 §2.6 |

> **文字层级三档**：标题用 `--text`，正文用 `--text-sub`，辅助用 `--text-faint`。不要用纯黑或纯灰。

### 2.3 ⚠️ 语义色（最重要的约定）

这组颜色**不是装饰**，每个都有明确的数据含义。**用错会让用户误读数据**。

| Token | 值 | 语义 | 用在哪 |
|---|---|---|---|
| `--real` | `#0fae8e`（同 brand） | **真实电耗** | 真实电耗折线、对比图中的真实电耗柱、图例 |
| `--price` | `#f59e0b` | **用电均价** | 均价折线、均价柱、图例 |
| `--disp` | `#6366f1` | **表显电耗** | 对比图中的表显柱、图例 |
| `--orange` | `#f59e0b` | 警告 / 充电时长 | 橙色警示条、警告文案、充电时长柱 |
| `--red` | `#e5484d` | 错误 / 异常 | 校验错误、异常记录、删除按钮 |
| `--blue` | `#2563eb` | 中性强调 / 里程 | 累计行驶指标、链接类强调 |

**关键约定**：

```
✅ 真实电耗 = 绿色系     （品牌色，代表"我们算出来的准数"）
✅ 用电均价 = 橙色系     （钱，颜色偏暖）
✅ 表显电耗 = 紫色系     （车机报的，"别人的数"）
❌ 禁止把三者互换或用同一个颜色
```

> **双轴图表的例外**：「充电时长与度数」中，时长用 `--brand` 绿、度数用 `--price` 橙。为避免与「均价橙」混淆，该图有独立图例说明。

### 2.4 状态色（明细页徽章）

| 状态 | 底色 | 文字色 |
|---|---|---|
| `ok` 完整 | `#e7f6ec` | `#16a34a` |
| `pending` 待补全 | `#fef3e2` | `#d98307` |
| `err` 异常 | `#fdeaea` | `#e5484d` |
| `baseline` 基准 | `var(--brand-soft)` | `var(--brand-strong)` |

### 2.5 功能色

| 用途 | 值 |
|---|---|
| 输入框聚焦环 | `0 0 0 3px var(--brand-soft)` |
| 输入框错误底 | `#fff5f5` + `var(--red)` 边框 |
| 警示条 | 文字 `#a8532d` / 底 `#fff6ed` / 边框 `#f7d9bf` |
| 错误条 | 文字 `#a32d2d` / 底 `#fcebeb` / 边框 `rgba(163,45,45,.28)` |

### 2.6 ⚠️ 一个被遗忘的 token

`--bg-grad` 在 `:root` 中定义，但**全项目从未引用**（`grep` 可验证）。

历史原因：登录页 `.auth-hero` 是白字白图标，但外层容器没有背景色，导致白字直接落在浅灰 `--bg` 上几乎看不见（2026-10-05 修复）。

**当前用法**：登录页/注册页已改用 `var(--brand-grad)` 铺满全屏，视觉层次更好。`--bg-grad` 保持定义但不引用，作为历史记录。

## 3. 字体

### 3.1 字体栈

```css
font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto,
             'PingFang SC', 'Microsoft YaHei', 'Helvetica Neue', Arial, sans-serif;
```

系统字体栈，**不引入 web font**（省体积、避免 FOUT）。中文靠 `PingFang SC`（iOS/macOS）与 `Microsoft YaHei`（Windows）。

根字号 `15px`。

### 3.2 字号阶梯

| 层级 | 移动端 | 桌面（≥900px） | 超宽（≥1440px） | 字重 | 用途 |
|---|:---:|:---:|:---:|:---:|---|
| 统计大数 | 23px | 27px | 30px | 800 | 指标卡数值 |
| 页面/卡片标题 | 16px | 17.5px | 19px | 700~800 | 卡片标题、页面标题 |
| 区块标题 | 18px | — | — | 800 | Hero 车型名 |
| 弹窗标题 | 18px | — | — | 800 | sheet 标题 |
| 正文 | 15px | 15px | 15px | 400 | 全局基准 |
| 记录时间 | 14px | 15px | — | 700 | 列表主信息 |
| 导航项 | 11px | 15px | 15.5px | 600 | Tab 项 |
| 字段标签 | 13px | 14px | — | 500 | 表单 label |
| 说明文字 | 12px | 13px | — | 400~500 | hint-text |
| 单位/后缀 | 12px | 13px | — | 500 | `.u` 单位 |
| 徽章 | 11px | — | — | 700 | 状态 badge |
| 错误提示 | 11.5px | 12.5px | — | 400 | `.err` `.warn` |
| 辅助说明色 | 11px | — | — | 500 | 隐私、占位 |

**移动端到桌面的放大逻辑**：不是简单 `transform: scale()`，而是**按信息层级分级放大**——标题与数字放大最多（+17%），正文几乎不变（15px 保持），辅助文字适度放大（+8%）。这样既利用了桌面空间，又不会让次要信息抢焦点。

### 3.3 行高

| 场景 | 行高 |
|---|---|
| 全局 | 1.55 |
| 帮助正文 | 1.8（长文阅读） |
| 错误提示 | 1.4 |
| 图例 | 默认 |

### 3.4 其它排版约定

| 属性 | 值 | 原因 |
|---|---|---|
| 统计数字 `letter-spacing` | `-0.5px` | 大号数字在默认字距下显得松散 |
| 页面标题 | `letter-spacing: 0.2px` | 微调，避免完全居中感 |

## 4. 圆角

| Token | 值 | 用途 |
|---|---|---|
| `--radius` | `18px` | 卡片、弹窗（桌面端升至 20px） |
| `--radius-sm` | `12px` | 徽章、小按钮、图标按钮 |
| — | `10px` | 摘要条、警示条、提示条 |
| — | `14px` | 指标卡、报表表格 |
| — | `8px` | 分段控件按钮、字段输入（`4px`） |
| — | `20~22px` | 桌面端弹窗（`border-radius: 22px`） |
| — | `17~19px` | Hero 车辆卡（56~62px 容器） |
| 徽章 | `20px` 全圆角 | 胶囊标签 |

**层级规律**：容器越大，��角越大（`4px` 输入 → `10px` 摘要 → `14px` 指标卡 → `18~20px` 卡片 → `22px` 弹窗）。

## 5. 阴影

| Token | 值 | 用途 |
|---|---|---|
| `--shadow-sm` | `0 1px 3px rgba(16,40,33,.06)` | 悬停、卡片头、指标卡 |
| `--shadow` | `0 2px 8px rgba(16,40,33,.06), 0 8px 24px rgba(16,40,33,.05)` | 一般卡片 |
| Hero 卡 | `0 4px 16px rgba(15,174,142,.25)` | **带品牌色**的绿调阴影 |
| 登录卡片 | `0 10px 30px rgba(9,68,55,.22)` | 绿底上的卡片用绿调投影 |
| Logo | `0 6px 18px rgba(0,0,0,.18)` | 白色 Logo 底块 |
| 无 | — | 表格、列表项、徽章 |

**原则**：阴影用**中性黑绿调**（`rgba(16,40,33,α)`），不用纯黑（脏）。品牌相关的卡片用**品牌色调**（`rgba(15,174,142,α)`），不用中性。

## 7. 组件规范

### 7.1 卡片 `.card`

```css
background: var(--surface);
border: 1px solid var(--border);
border-radius: var(--radius);
box-shadow: var(--shadow-sm);
```

- 桌面端圆角升至 `20px`
- 内部标题行 `.card-head`：标题 17.5px 700，左侧 16px 图标
- 右上角可放 `.tag` 标签

### 7.2 指标卡 `.stat`

**特色设计**：左侧 3px 竖条用渐变区分主/次要指标。

```css
.stat::before {
  content: ''; position: absolute; left: 0; top: 0; bottom: 0; width: 3px;
  background: var(--brand-grad);        /* 主指标 */
}
.stat.alt::before {
  background: linear-gradient(180deg, #fbbf24, #f59e0b);  /* 次指标，对应均价橙 */
}
```

| 指标 | 类名 | 竖条 | 图标色 |
|---|---|---|---|
| 真实电耗 | `.stat` | 品牌绿渐变 | `ic-brand` |
| 用电均价 | `.stat.alt` | 橙渐变 | `ic-price` |
| 累计行驶 | `.stat` | 品牌绿渐变 | `ic-blue` |
| 累计花费 | `.stat.alt` | 橙渐变 | `ic-sub` |

> 竖条颜色**必须**与指标语义色一致（均价=橙，电耗=绿），用户不看文字也能分辨。

### 7.3 图表标题 `.chart-title`

`14px / 600 / var(--text-sub)`，配 14px 图标。标题在上、图表在下。

### 7.4 图例 `.legend`

```css
font-size: 13px; color: var(--text-sub); gap: 16px;
```

色块 `10×10px`，圆角 3px，紧跟 5px 间距。**仅用于语义不直观的图**（对比图、充电时长图）；单序列图不加图例。

### 7.5 分段控件 `.seg-control`

移动端横向排布。按钮 `13px/600`，选中态白底 + `--shadow-sm` + `--brand-strong` 文字。

登录/注册切换、概览周期筛选共用此组件。

### 7.6 警示条 `.warn-bar`

破坏性操作的橙色提示条，**必须**带 `AlertTriangle` 图标。

```css
color: #a8532d; background: #fff6ed; border: 1px solid #f7d9bf;
border-radius: 10px; padding: 10px 13px; font-size: 13px;
```

### 7.7 空状态 `.empty`

居中布局，30px 图标（`opacity: .6`）+ 说明文案 + 可选引导。

**统一使用 `lucide-vue-next` 线性图标**，不混用其他图标库。

| 语义 | 图标 | 尺寸 |

| 概览 | `LayoutDashboard` | Tab 21px / 移动 22px |
| 记录 | `ClipboardList` | 同上 |
| 分析 | `PieChart` | 同上 |
| 数据 | `Database` | 同上 |
| 帮助 | `CircleHelp` | 同上 |
| 真实电耗 | `Zap` | 13~14px |
| 均价 | `Coins` | 13~14px |
| 里程 | `Route` | 13~14px |
| 花费 | `Wallet` | 13~14px |

**颜色类**（`.ic-brand` / `.ic-price` / `.ic-blue` / `.ic-sub` / `.ic-red`）必须跟随语义色，**禁止在组件里写死颜色**。

## 9. 落地页对比度

| 元素 | 前景 | 背景 | 对比度 |
|---|---|---|:---:|
| 卡片标题 | `--text` `#0f1c17` | `#ffffff` | ≈ 17:1 ✅ AAA |
| 正文 | `--text-sub` `#5d6b65` | `#ffffff` | ≈ 6.4:1 ✅ AA |
| 辅助说明 | `--text-faint` `#93a09a` | `#ffffff` | ≈ 2.8:1 ⚠️ 仅用于非关键信息 |
| 输入框文字 | `--text` | `--surface-2` | ≈ 16:1 ✅ |
| 错误提示 | `--red` `#e5484d` | `#ffffff` | ≈ 4.2:1 ✅ |
| 橙色警示 | `#a8532d` | `#fff6ed` | ≈ 5.8:1 ✅ |
| **登录页标题** | `#ffffff` | `--brand-grad` | ≈ 3.1:1 ✅（大字号文本） |
| **登录页副标题** | `rgba(255,255,255,.95)` | `--brand-grad` | ✅ |

> ⚠️ `--text-faint` 对比度偏低，**只能用于「字号小 + 非关键」的辅助信息**（单位、占位、免责说明），不得用于需要用户读取的关键数据。

## 10. 动效

全站动效克制，只用功能性过渡：

| 场景 | 参数 |
|---|---|
| 分段控件切换 | `all 0.12s ease` |
| 按钮悬停 | `border-color` 渐变 |
| 卡片悬停（列表项） | 阴影加深 |

**不使用**弹入、缩放、位移等装饰性动效。ECharts 图表本身有 `smooth: true` 的曲线平滑（数据可视化需要，不算装饰）。

## 11. 规范约束（给 AI 与协作者）

| 规则 | 说明 |
|---|---|
| 🚫 禁止写死颜色 | 一律用 CSS 变量或语义类 |
| 🚫 禁止新增「好看的颜色」 | 只有语义色；需要新色必须先说明语义 |
| 🚫 禁止在组件内写断点 | 断点统一在 `style.css` 末尾集中管理 |
| ✅ 新组件先复用 | 看看能不能用现有 `.card` / `.stat` / `.badge` / `.hint-text` 组合出来 |
| ✅ 图标必须用 lucide | 不用 emoji 代替功能图标 |
| ✅ 圆角按容器大小选 | 参照 §4 层级规律 |
| ✅ 阴影跟着语境走 | 中性面用中性阴影，品牌面用品牌阴影 |
